# Rezka TV+ — канал для Roku (v0.8.0)

Автономний канал для перегляду rezka на Roku TV. Усе працює на самому
телевізорі — ні комп'ютер, ні ТВ-приставка після встановлення не потрібні.

## Встановлення (просте, через браузер — з комп'ютера або з телефона)

Знадобиться лише файл **`rezka-tv-plus.pkg`** і 5 хвилин.

### Крок 1. Увімкнути режим розробника на ТВ (один раз)

На пульті Roku натисни послідовно, чітко, не швидко:

**Home ×3, потім Вгору ×2, потім Вправо, Вліво, Вправо, Вліво, Вправо**

Відкриється екран **Developer Settings**:

1. Випиши **IP-адресу телевізора** — вона показана просто на цьому екрані
   (наприклад, `192.168.0.2`).
2. Вибери **Set password** і задай пароль веб-інсталятора (запам'ятай його).
3. Погодься з умовами — телевізор перезавантажиться.

> Якщо екран не відкривається — натискай повільніше, з паузою між кнопками.

### Крок 2. Відкрити сторінку встановлення

Телефон/комп'ютер має бути в **тій самій Wi-Fi мережі**, що й ТВ.

Відкрий у браузері: **`http://IP-телевізора`** (наприклад, `http://192.168.0.2`)

Браузер запитає логін і пароль:
- логін: **`rokudev`**
- пароль: той, що задав на кроці 1.

Відкриється сторінка **Development Application Installer**.

### Крок 3. Завантажити канал

**З комп'ютера:**
1. Кнопка **Upload** → вибери файл `rezka-tv-plus-0.8.0.pkg`.
2. Натисни **Install**. За кілька секунд з'явиться «Install Success».

**З телефона:**
1. Спершу скачай `rezka-tv-plus-0.8.0.pkg` на телефон (з релізу на GitHub — у «Завантаження»).
   Архів **розпаковувати не потрібно**.
2. Відкрий `http://IP-телевізора` у браузері телефона (Chrome/Safari),
   увійди як на кроці 2.
3. **Upload** → вибери файл із «Завантажень» → **Install**.
   - iPhone: під час вибору файлу натисни «Огляд» → папка «Завантаження» у «Файлах».
   - Android: вибір файлу → «Завантаження» (Downloads).

Готово — канал **Rezka TV+** з'явиться на головному екрані Roku останнім у списку.

> На Roku одночасно може бути встановлено **не більше одного** dev-застосунку:
> встановлення нового автоматично замінює попередній.

## Оновлення каналу

Нічого видаляти не треба:

1. Скачай новий `rezka-tv-plus.pkg` (телефон або комп'ютер).
2. Відкрий `http://IP-телевізора` → увійди (`rokudev` + пароль).
3. **Upload** → файл → **Install** (сторінка сама запропонує **Replace** — погоджуйся).

Усі налаштування, історія та обране зберігаються.

## Перший запуск

- **Увійти в акаунт rezka** — продовження перегляду, нові серії, Ultra-якість,
  синхронізація прогресу з сайтом. Логін/пароль зберігаються лише на ТВ.
- **Гість** — без акаунта: каталог, пошук, історія на самому ТВ (якість до 1080p).

## Що всередині (0.8.0)

- Каталог, добірки, пошук з екранною клавіатурою.
- Картка тайтлу: опис, усі частини франшизи / схожі (перемикач),
  обране, вибір якості, вибір озвучення, серії за сезонами.
- Додивляння з місця зупинки (синхронізується з сайтом, коли сайт нормально працює), прогрес кожні 30 с.
- Стрічка внизу: новини або «Для тебе» (нові серії, схожі на переглянуте).
- Святкові теми в налаштуваннях: **Свята (авто) / Стандарт / Україна / 18+**.
- Дитячий режим: власна мультяшна тема, ліміт часу, вікові обмеження, PIN.
- Розділ 18+ під PIN (вмикається в налаштуваннях, окрема тема оформлення).

## Керування

| Кнопка | Дія |
|---|---|
| ← ↑ ↓ → | навігація |
| OK | вибрати / пауза |
| Back | назад |
| Rew / FF | перемотка в плеєрі, сторінки каталогу |
| * | опції (у ТВ-режимі — меню каналу) |
| ▶ (Play) | пауза / продовжити |

## Якщо щось пішло не так

- **«Install Failure»** — найчастіше пошкоджений файл під час скачування:
  скачай файл наново й повтори. Переконайся, що завантажуєш саме pkg.
- **Сторінка `http://IP-ТВ` не відкривається** — телефон/комп'ютер не в тій Wi-Fi
  мережі, або ТВ перезавантажувався й змінив IP (подивись актуальну IP:
  Налаштування Roku → Мережа → Про з'єднання).
- **Логи для налагодження** (необов'язково): на комп'ютері в терміналі
  `nc IP-телевізора 8085` — там усі службові повідомлення каналу.
- Режим розробника зберігається безстроково, але після скидання/перепрошивки ТВ
  крок 1 потрібно пройти наново.
