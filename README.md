# Rezka TV+ — канал для Roku (v0.8.0)

Автономный канал для просмотра rezka на Roku TV. Всё работает на самом
телевизоре — ни компьютер, ни сервер после установки не нужны.

## Установка (простая, через браузер — с компьютера или с телефона)

Понадобится только файл **`rezka-tv-plus-0.8.0.pkg`** и 5 минут.

### Шаг 1. Включить режим разработчика на ТВ (один раз)

На пульте Roku нажми последовательно, внятно, не быстро:

**Home ×3, затем Вверх ×2, затем Вправо, Влево, Вправо, Влево, Вправо**

Откроется экран **Developer Settings**:

1. Выпиши **IP-адрес телевизора** — он показан прямо на этом экране
   (например, `192.168.0.247`).
2. Выбери **Set password** и задай пароль веб-инсталлятора (запомни его).
3. Согласись с условиями — телевизор перезагрузится.

> Если экран не открывается — нажимай медленнее, с паузой между кнопками.

### Шаг 2. Открыть страницу установки

Телефон/компьютер должен быть в **той же Wi-Fi сети**, что и ТВ.

Открой в браузере: **`http://IP-телевизора`** (например, `http://192.168.0.247`)

Браузер спросит логин и пароль:
- логин: **`rokudev`**
- пароль: тот, что задал на шаге 1.

Откроется страница **Development Application Installer**.

### Шаг 3. Загрузить канал

**С компьютера:**
1. Кнопка **Upload** → выбери файл `rezka-tv-plus-0.8.0.pkg`.
2. Нажми **Install**. Через несколько секунд появится «Install Success».

**С телефона:**
1. Сначала скачай `rezka-tv-plus-0.8.0.pkg` на телефон (из чата/почты — в «Загрузки»).
   Архив **распаковывать не нужно**.
2. Открой `http://IP-телевизора` в браузере телефона (Chrome/Safari),
   войди как на шаге 2.
3. **Upload** → выбери zip из «Загрузок» → **Install**.
   - iPhone: при выборе файла нажми «Обзор» → папка «Загрузки» в «Файлах».
   - Android: выбор файла → «Загрузки» (Downloads).

Готово — канал **Rezka TV+** появится на главном экране Roku последним в списке.

> На Roku одновременно может быть установлено **не больше одного** dev-приложения:
> установка нового zip автоматически заменяет предыдущий.

## Обновление канала

Ничего удалять не надо:

1. Скачай новый `rezka-tv-plus-0.8.0.pkg` (телефон или компьютер).
2. Открой `http://IP-телевизора` → войди (`rokudev` + пароль).
3. **Upload** → zip → **Install** (страница сама предложит **Replace** — соглашайся).

Все настройки, история и избранное сохраняются.

## Первый запуск

- **Войти в аккаунт rezka** — продолжение просмотра, новые серии, Ultra-качество,
  синхронизация прогресса с сайтом. Логин/пароль хранятся только на ТВ.
- **Гость** — без аккаунта: каталог, поиск, история на самом ТВ (качество до 1080p).

## Что внутри (0.8.0)

- Каталог, подборки, поиск с экранной клавиатурой, бесконечная лента.
- Карточка тайтла: описание, все части франшизы / похожие (переключатель),
  избранное, выбор качества, выбор озвучки, серии по сезонам.
- Досмотр с места остановки (синхронизируется с сайтом), прогресс каждые 30 сек.
- Лента внизу: новости или «Для тебя» (новые серии, похожие на просмотренное).
- Праздничные темы: 24 праздника (Канада, Украина, мировые) — сами включаются
  по дате за неделю до и после; рамки постеров, летающие частицы и палитра
  меняются. В сам день праздника — поздравление рядом с датой вверху.
  Режимы в настройках: **Праздники (авто) / Стандарт / Украина / 18+**.
- Детский режим: своя мультяшная тема, лимит времени, возрастные ограничения, PIN.
- Раздел 18+ под PIN (включается в настройках, отдельная тема оформления).

## Управление

| Кнопка | Действие |
|---|---|
| ← ↑ ↓ → | навигация |
| OK | выбрать / пауза |
| Back | назад |
| Rew / FF | перемотка в плеере, страницы каталога |
| * | опции (в ТВ-режиме — меню канала) |
| ▶ (Play) | пауза / продолжить |

## Если что-то пошло не так

- **«Install Failure»** — чаще всего повреждённый zip при скачивании:
  скачай файл заново и повтори. Убедись, что грузишь именно zip, не распаковку.
- **Страница `http://IP-ТВ` не открывается** — телефон/компьютер не в той Wi-Fi
  сети, или ТВ перезагружался и сменил IP (посмотри актуальный IP:
  Настройки Roku → Сеть → О подключении).
- **Логи для отладки** (необязательно): на компьютере в терминале
  `telnet IP-телевизора 8085` — там все служебные сообщения канала.
- Режим разработчика сохраняется бессрочно, но после сброса/перепрошивки ТВ
  шаг 1 нужно пройти заново.
